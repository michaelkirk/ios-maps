maps.earth style guide

Colour, type and spacing for maps.earth on iOS and the web, and the map style they share. Contrast ratios are WCAG; AA wants 4.5:1 for body-size text.

Green is GO and system red is End Navigation: go and stop, never a quality. hw_go sits between system green and its Increase Contrast shade: deep enough for white bold type, bright enough to still read as go. The neutrals are slightly blue (hue 200–208), so warm greys look dirty beside them.

Accents: teal and amber

Teal (hue 176) and amber (hue 36) are for describing things without passing judgement, like which route is comfier or faster, or how steep a hill is. Neither hue is taken, and they are 140° apart. Each has five steps: 50 and 100 are washes to put type on, 500 is for shapes, and 600 and 700 are for type.

Don't: put type on a 500, give anything that isn't a control a saturated fill, or add a second solid colour to a row that already has a button. A button's colour stays the same whatever state the thing is in. A saved place's Save button keeps its white fill, and its glyph shows how the place was saved.

To add an accent:

  1. Pick a hue that isn't taken: blue (204) is selection, green (127) is home and GO, red (6) is work and stop.
  2. Keep it at least 30° from any accent it will appear next to.
  3. Build five steps at the same lightness as teal and amber.
  4. Check that 700 on 100 and 700 on white both reach 4.5:1.
  5. Run it through a colour-blindness simulation if it's the only thing telling two rows apart.

On the map

A graded route is still the chosen route, so its line is hw_activeRoute, or hw_inactiveRoute if it isn't selected. Steep stretches are drawn over it: amber for climbs, darker as they get steeper, and teal for descents of 13% or more (travelmux decides which descents those are). Climb pills use the chip style, 700 on 100, outlined in the stretch's shade.

StretchColour
Flat, or a moderate descent hw_activeRoute
Moderate climb hw_amber500
Steep climb hw_amber600
Very steep climb hw_amber700
Descent, 13% or more hw_teal700

Wherever grades appear as text, such as elevation totals, chart labels and the hill rows in a trip's steps, they use the 700 ink: amber for climbs, teal for descents. The steepness is in the number; the shade is only for shapes. The elevation chart's line uses the route's blue.

Road shields

Road shields shouldn't stand out more than the route line. The basemap is #F1EFE7 and its roads are greys between 68% and 52% lightness. The interstate shield sets the ceiling:

HexOn basemap
Body #1966B35.08:1
Band #C431424.72:1

White type on the body is 5.84:1. No shield should be darker than #1966B3. That covers both blanks and shield text, so a network whose official colour is navy uses #1966B3 instead.

Typography

Type scale

All text uses one of seven roles. On iOS a role is a text style, so it follows the reader's Dynamic Type setting. On the web it's a class sized in rem, so it follows the browser's font size. Sizes below are at the default setting. The web runs a step smaller, matching its 14px body text.

  • One title per sheet. Everything else in the sheet is a step down from it.
  • A row leads with one thing. A trip row leads with its figure; a search result with its heading. Nothing else in the row is as heavy.
  • Secondary text goes with another line. It sits under or beside the line it describes, and is never the only text in a row.
  • Change weight before size. Going up a step changes the weight first: body and heading are both 17pt, regular and semibold.
  • Don't pin a size. Don't use .dynamicTypeSize(_:) or .system(size:) on text in a sheet, or px font sizes on the web.

The exception is type inside fixed-size artwork, which keeps a fixed size: climb pills on the map (11pt bold), elevation chart labels (10pt bold), transit vehicle markers, and GO (20pt bold in a 56pt square).

Spacing

Gaps between elements come from a five-step scale, Space on iOS. The inset around a sheet or a card is .padding(), which equals Space.l.

TokenPointsFor
Space.xs4Chips next to each other; a line and its secondary
Space.s8Lines within a row
Space.m12A value and its label across a row
Space.l16An icon and its text; sheet and card insets
Space.xl24Between groups

A component's own insets, like a chip's 10pt × 5pt, are set for that component and defined where it's drawn.

Known gaps

  • Secondary text is below AA. hw_darkGray is 3.95:1 on white and about 3.4:1 on the sheet. #6B7177 would be 4.9:1 on white and keep the palette's cool tint.
  • No dark mode. Every token is a fixed RGB. In a dark theme the accent steps should swap roles instead of inverting: 700 becomes the wash and 100 becomes the type.
  • The web has no spacing scale yet. Its gaps are set per component.
